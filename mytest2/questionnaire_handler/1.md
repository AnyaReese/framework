#### 问卷处理部分说明：

- 将问卷中某些决定问卷走向哪个分支的问题作为router，分支放进block中，实现对问卷的一个切块。
  - 很好的契合我们目前LLM2-1负责router，LLM2-2负责填写问卷的架构。

##### 具体过程：

- 手动筛选router问题：debug_questionnaire_graph.py脚本能输出问卷的mmd树状图结构,发现某些问题是导致问卷分支的关键问题,把这样的问题拿出来作为router。

- 代码切分router以及blocks：debug_split_questionnaire_subtrees.py脚本负责切分。生成

  1. questionnaire_split_subtrees.json
     这是“总结果文件”。
     里面包含：
     - 每个模块的 summary
     - 每个模块的 router 问题
     - 每个模块的 blocks
     - 每个 block 的 question_ids、edges、router_path 等完整调试信息

  2. questionnaire_routers.json
     这是“只保留 router”的精简文件。对应LLM2-1使用
     里面主要是：

     - 每个模块有哪些 router 问题

     - 每个 router 的选项

     - router 之间的依赖关系 router_edges

  3. questionnaire_blocks.json
     这是“只保留 blocks”的精简文件。对应LLM2-2使用
     里面主要是：

     - 每个模块有哪些 block

     - 每个 block 的名字

     - block 对应哪些问题

     - 这个 block 是被哪个 split 节点 / 哪个选项激活的
